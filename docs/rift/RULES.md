# Deterministic rules

Current version `rift-rules-2` (2026-10-17 repair): 400g boots remain early; Tier 2 normally follows first major, with an editable earlier-Tier-2 preference. Tier 3 normally follows four major purchases and remains gated ≥10:00 in ranked/PvP; it is withheld in ARAM variants. Heavy observed burst (authored mean ≥2) accelerates an existing Hourglass target after first core and prioritises its Armguard component before greedy AP. The component is **not** an active Stasis and its armour is not magic resistance. It does not create a seventh slot or invent income/sale credit. The next-purchase adapter credits entered recipe components exactly once, checks capacity, available gold and game-time gates. These remain explainable heuristics, not optimal timing predictions.

Quick threats use only known, kit-covered enemies. Short named actions retain the source kit/tactics; full warnings are in detailed analysis. Removing a threat need not change a build when another enemy still satisfies its rule. Screenshot similarity is excluded from strategy inputs until user review. A scoreboard sets postgame; locked rune/spell suggestions are informational, not actionable changes.

Rule version starts at `rift-rules-1`. Utility scores rank the player's editable pool; they are uncalibrated, not win probabilities. Components: proficiency/preference, role suitability, objective, risk, composition gap, ally CC follow-up, enemy burst/sustained damage/mobility/CC/healing/shields/resistances. Only known champions contribute; unknown kits/slots reduce coverage instead of receiving invented values. Practice prioritises preference; MVP is a participation/survival proxy, never Riot's scoring formula. Stable ID tie-breaks make replay deterministic.

Builds use data templates plus universal substitutions. Swain has aggressive AP, drain fighter and flexible battlemage templates. Healing can justify anti-heal (trade damage for utility); shields can justify shield reduction; CC/magic or attacks can change boots; burst can advance a defensive item; resistant targets can justify penetration. These are hypotheses for user choice, not optimality proofs. Champion-specific tactical exceptions are small, explicit data records. Spell recommendations enforce jungle Smite and mode restrictions.

Validate rune shape, duplicates, primary rows and secondary tree. Validate five major items, one boot, mode/patch/removed status, unique/passive groups and mana/champion restrictions. Support plan shows a retained quest item + four majors + boots before optional final sale. Purchase steps use recipes and incremental costs, conserve total gold, show intermediate boots, avoid claiming recall timestamps or income. Tier 3 upgrade advice is time-gated and deferred in modes without verified timing. Recalculate from visible inputs on every change.

All output contains reason codes, signed score components, trade-offs and coverage. Saved advice pins structured input, full output, patch/data/rule versions and actual save time. Final inventory observations never imply actual purchase order.

The current corpus scores only champions with both a reviewed kit and a build template. Other roster/kit entries are visible but never silently receive a build. Bans and ranked enemy picks exclude candidates; conflicting locked selections disable builds. Duplicate picks across ranked teams warn. Spell, rune and item rationales are qualitative, retained in the frozen output, and do not simulate their exact numerical effects. The chosen build tab is saved as `presentedBuild`, so analysis can identify the advice actually shown.
